# arduino-giga-base
This is the base repository for Keck projects using the Arduino GIGA R1 WiFi board.

<https://docs.arduino.cc/hardware/giga-r1-wifi/>

Curently (August 2025) the first sketch to lay the foundation for the general architecture of projects that all use the GIGA R1 WiFi device, is for a sensor.  [Click here for documentation of the Sole Digital Rope Load Cell sensor project.](doc/Sole_Digital_Rope_Load_Cell_Sensor.md)

Subsequent projects shall expand this code base and separate the re-usable components into subdirectories for inclusion in your future project.
